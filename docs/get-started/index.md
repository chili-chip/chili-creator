# Get started

The Chili Creator is a collection of game editors. These pages are the same for
every editor. They get you from no account to finding your way around.

| Page | You learn |
|---|---|
| [Open the creator](open-the-creator.md) | Make an account, open the creator, start or import a game, and how saving works |
| [The workspace](workspace.md) | The tool bar, docked tools, layouts, the command palette, undo and the tour |
| [Projects](projects.md) | Start, open, import, copy, delete, release and update games, in any editor |
| [On a phone](phone.md) | One tool at a time, the tool bar along the bottom, and touch controls in Play |

Then pick an editor and build your first real game:

| Editor | Makes | Tutorial |
|---|---|---|
| [Bitsy editor](../editors/bitsy/index.md) | Story games with rooms, characters, dialog and endings | [Chili Garden](../editors/bitsy/tutorial/index.md) |
| [Chili Beat editor](../editors/beat/index.md) | Games where things bump, move and change on the beat | [Bee Home](../editors/beat/tutorial.md) |

Not sure which? See [Editors](../editors/index.md).

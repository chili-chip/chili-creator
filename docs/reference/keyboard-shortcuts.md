# Keyboard shortcuts

++ctrl++ is ++cmd++ on a Mac. Shortcuts wait while you type in a text field, except ++ctrl+k++.

## Everywhere

| Keys | Does |
|---|---|
| ++ctrl+k++ | Open the command palette |
| ++ctrl+z++ | Undo |
| ++ctrl+shift+z++ or ++ctrl+y++ | Redo |
| ++escape++ | Close the command palette or Help |

## Room

| Key | Tool |
|---|---|
| ++p++ | Place |
| ++e++ | Erase |
| ++i++ | Pick what is on a cell |
| ++x++ | Add exits |
| ++n++ | Add endings |

## Paint

| Key | Tool |
|---|---|
| ++b++ | Pencil |
| ++f++ | Fill |

## Play

Click the game screen first so it gets the keys.

| Keys | Button |
|---|---|
| ++arrow-up++ ++arrow-down++ ++arrow-left++ ++arrow-right++ or ++w++ ++a++ ++s++ ++d++ | Move |
| ++space++, ++enter++, ++z++ or ++x++ | Ok: talk, next page, start |
| ++escape++ | Menu |

## Command palette

Everything else is in the palette: open any tool (*Open Tunes*), choose a layout (*Layout: Writing*), reset the layout, take the tour, or open Help. Type a few letters of it and press ++enter++.

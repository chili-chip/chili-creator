# Chili RPG tools

A Chili RPG game shows these tools next to [Projects](../../../get-started/projects.md).
Each has a button in the tool bar, and **Help** in the creator links to these pages.

| Tool | Use it to |
|---|---|
| [Rooms](rpg-rooms.md) | Paint the ground and the top layer, place people, items, warps, triggers and the start, and size each room. |
| [Art](rpg-art.md) | Draw the pictures for tiles, people and items. |
| [Tiles](rpg-tiles.md) | Set up the kinds of ground: picture, animation, solid, water, save point, damage. |
| [Hero](rpg-hero.md) | Set the hero's look, stats and levels, and what happens when the hero dies. |
| [Characters](rpg-characters.md) | Make people and enemies: look, brain, stats, drops, dialogue and events. |
| [Items](rpg-items.md) | Make potions, gear, keys and quest items, and the equipment slots. |
| [Dialogue](rpg-dialogue.md) | Write what people say, with lines that depend on the story and choices that jump. |
| [Quests](rpg-quests.md) | Write quests in stages, each with a goal and an event when it is met. |
| [Play](rpg-play.md) | Play the game in the real engine, with the room, HP and quests shown under it. |
| [Problems](rpg-problems.md) | Find what would stop the game from playing. |
| [Game](rpg-game.md) | Set the author, background, start and the rules for steps, the bag and damage. |

Many tools hold an [event](../events.md) form. Undo, autosave and the title
work the same in every editor. See [The workspace](../../../get-started/workspace.md).

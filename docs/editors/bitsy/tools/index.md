# Bitsy editor tools

A Bitsy game shows these 14 tools next to [Projects](../../../get-started/projects.md), which every editor shares. Each one has a button in the tool bar and a page here. **Help** in the creator links to these pages too.

| Tool | Use it to | Key commands |
|---|---|---|
| [Room](room.md) | Draw tiles, place sprites and items, add exits and endings | ++p++ ++e++ ++i++ ++x++ ++n++ |
| [Paint](paint.md) | Draw a tile, sprite or item, animate it, give it a sound | ++b++ ++f++ |
| [Library](library.md) | Browse, pick, add, copy and delete tiles, sprites and items | |
| [Colors](colors.md) | Edit palettes and choose one per room | |
| [Dialog](dialog.md) | Write what sprites and items say, as text or blocks | |
| [Exits & endings](exits.md) | Set where exits lead, transitions, locks and ending text | |
| [Variables](variables.md) | Make variables and set the items the avatar starts with | |
| [Tunes](tunes.md) | Write music for rooms | |
| [Blips](blips.md) | Make short sound effects | |
| [Problems](problems.md) | Find what would break the game | |
| [Play](play.md) | Play the game, watch inventory and variables, record a GIF, set a cover | |
| [Game](game.md) | Change the title, font, text direction and size, or edit the raw `.bitsy` | |
| [Download](download.md) | Save the `.bitsy` file or a web page that plays the game | |
| [Find](find.md) | Search everything and see where a drawing is used | |

Everything you pick is shared between tools: pick a sprite in Library and Paint draws it, Room places it and Dialog shows what it says.

To arrange the tools, see [The workspace](../../../get-started/workspace.md).

The [Chili Beat editor](../../beat/tools/index.md) has its own tools.

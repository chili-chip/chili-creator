# Chili Beat tools

A Chili Beat game shows these tools next to [Projects](../../../get-started/projects.md).
Each has a button in the tool bar, and **Help** in the creator links to these pages.

| Tool | Use it to |
|---|---|
| [Screens](beat-screens.md) | Paint things and ground on each screen, and lay out screens on the world map. |
| [Things](beat-things.md) | Draw the things in a Chili Beat game, name them and choose which ones are you. |
| [Rules](beat-rules.md) | Build the rule cards that decide everything in a Chili Beat game, and add recipes. |
| [Sounds](beat-sounds.md) | Make sound effects and 16-step tunes for a Chili Beat game. |
| [Play](beat-play.md) | Play a Chili Beat game and watch its rule cards light up. |
| [Problems](beat-problems.md) | Find what would stop a Chili Beat game from playing. |
| [Game](beat-game.md) | Set a Chili Beat game's colours, tempo, time, start screen and counters. |

Undo, autosave and the title work the same in every editor. See
[The workspace](../../../get-started/workspace.md).
